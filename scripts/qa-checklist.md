- [ ] Auth and RBAC verified for every module route.

- [ ] Prescription issue updates stock and ledger.
- [ ] Admission -> Discharge blocked until required constraints pass.
- [ ] Billing supports partial + full payment and printable invoice.
- [ ] Dashboard metrics reconcile with source transactions.
- [ ] Scheduler jobs configured (reminders, low-stock alerts).
- [ ] Backups and restore test completed.
